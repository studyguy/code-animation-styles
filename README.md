# 代码动画风格提示词

341 种用代码做动画的视觉风格，每种一份提示词。**333 种带预览图**（其中 193 种是静帧，140 种是补的示意帧），31 种带原片链接。

> **English:** see [README.en.md](README.en.md) — and the picker itself has a full English UI (top-right button).
在线挑选：**https://studyguy.github.io/code-animation-styles/**

> 直接用浏览器打开 `风格挑选.html` 也能用，图片和提示词都在这一个文件里，不需要联网。

## 怎么用

1. 打开挑选页，按来源、分类、是否有图筛选，或者直接搜「水墨」「复古」「M8」。
2. 点任意预览图，左边看大图，右边看**提示词全文**（框内可滚动）、适合场景、导演说明和参考。
3. 勾选喜欢的，点右上角「已选清单」复制，连同你想做的东西一起发给 AI。
4. 让它输出一个能在浏览器打开的 HTML，再渲成视频。

提示词写得越细（颜色、时间、镜头都写死），不同模型做出来越接近。有些提示词里有 `{{ }}`，那是要自己填的地方。

## 预览图怎么来的

- **静帧 / 已有图**：原项目自带。
- **补的 140 张**：`preview/` 里用 Canvas 按各自提示词画出来，再无头 Chrome 截图。脚本都在，可以重跑：

```bash
cd preview
node render.js M5 K22        # 渲染指定条目
python audit.py              # 质检
python install.py            # 落盘（已存在的图会跳过，不覆盖）
```

- **M 系列 31 条**另有原片：卡片右下角「看原片」会内嵌打开 prompt-motion.com 的原页面，视频不走本地。
